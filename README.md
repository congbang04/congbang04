## 🚀 Featured Projects

### 🔧 Garage Chain Management System
> Full-stack Laravel application for managing multi-branch auto repair operations — built as final year thesis (individual project)

**Key highlights:**
- **Service-Oriented MVC** architecture — thin controllers, dedicated service classes, SOLID principles throughout
- **RESTful API** with 30+ endpoints — booking, orders, inventory, staff, branches, transactions
- **Real-time slot locking** via Laravel Reverb (WebSocket) — prevents double-booking across branches
- **Order state machine** — `received → quoted → in_progress → waiting_part → completed → paid`
- **AI Chatbot** powered by Gemini API for customer service advisory
- **15+ database tables** with polymorphic relationships, eager loading, optimized queries

`Laravel` `Eloquent ORM` `MySQL` `Laravel Reverb` `WebSocket` `Docker` `Gemini API` `Bootstrap 5`
